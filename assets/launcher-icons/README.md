# Fork launcher icons

Release, Pre, DEV and CI retain the cyan waffle and gold center from
`assets/guffawaffle-build-badge.png`. That original loading-screen image is
unchanged. The icon removes its loading-screen wording and uses the lower panel
for the build channel. Channel accents are cyan for Release, amber for Pre,
violet for the development package, and silver-blue for raw CI downloads.
CI is the ordinary build default; DEV is selected explicitly for the development
package. Neither icon itself enables development features.

The geometry in `scripts/generate-launcher-icons.py` is the single editable
source. Its labels use Pillow's bundled Aileron font, without relying on fonts
installed on the machine. Regenerate with Python and Pillow 12.3.0:

```sh
python -m pip install Pillow==12.3.0
python scripts/generate-launcher-icons.py
```

The PNG previews are 1024×1024 RGBA. Each ICNS uses the native ARGB encoding for
16- and 32-pixel icons, matching Apple's `iconutil`. Larger sizes use PNG at 128,
256, 512 and 1024 pixels, plus the 16@2x, 32@2x, 128@2x and 256@2x Retina entries.
PNG data in the small `icp4`/`icp5`/`icp6` slots can appear as coloured noise in
Finder, so those slots are omitted. The committed files are used directly by
builds; CI does not need Pillow or an icon generator.

An optional `--contact-sheet <path.png>` writes a preview at large, 64, 32 and 16
pixel sizes. `--output-dir <directory>` supports checking regenerated bytes
without modifying the committed assets.
