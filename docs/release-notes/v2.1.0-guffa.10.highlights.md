## Highlights

### Clear runtime identity

- The loaded mod now identifies itself as **Guffawaffle STFC Mod** and explicitly reports that it is an unofficial downstream build.
- Logs, runtime diagnostics, loading text, and Windows DLL metadata now use one canonical support identity with the release tag, build class, exact source, upstream base, distribution ID, and reproducibility state.

### Official-looking runtime branding removed

- Removed the mod-owned `Official CC` logo asset and its login and transition overlays.
- Removed generic loading text that presented the loaded build as the Community Mod.
- Default builds now retain the game's original loading background. Explicitly configured custom backgrounds remain supported.
- Upstream attribution, contributor credit, licensing, and factual upstream links remain intact.

### Release provenance is enforced

- Release and distributed test builds now fail closed when source identity is missing, malformed, dirty, or inconsistent with the checked-out commit.
- CI exercises clean, dirty, development, test, and release identity cases.

## What This Means For Players

- No configuration migration is required.
- The Windows proxy remains `version.dll`.
- Launcher, installer, bundle identity, install paths, and update channels are unchanged in this release.
- Support logs and detached Windows binaries can now be attributed to this exact downstream release.

## Upgrade Notes

- No special upgrade steps are required beyond replacing the existing mod artifact through the normal Windows or macOS update path.
