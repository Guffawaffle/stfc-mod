# DEV packages

The optional AAI and Profiles development product is maintained on `play-dev`.
Its Development package workflow, private-source setup and tag publishing tools
live on that branch, separately from this public release source.

Use the [play-dev publication guide](https://github.com/Guffawaffle/stfc-mod/blob/play-dev/docs/development-releases.md)
from that exact checkout when preparing a DEV package. A DEV tag on this branch
will not invoke that workflow. For normal signed Pre and Release packages, follow
[Downstream releases](DOWNSTREAM-RELEASES.md).
