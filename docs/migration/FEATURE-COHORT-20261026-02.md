## Verification and recovery

### Bounded corrections and retained behavior

- **Sort construction:** retain the existing typed menu producer and shared static
  delegate constructor. Restore the source's field preflight and temporary roots
  for both delegates, key strings, SortFunction and ProcessingOption through
  insertion. Typed static comparer/initialization signatures reject ABI drift;
  required comparers need native pointers. Optional tie-breakers retain source
  fallback behavior. No new hook target or SortComparer rewrite.
- **Shared delegate helper:** reuse the existing NewClosedDelegate custody/failure
  pattern in NewDelegate rather than duplicating a constructor in the feature.
  Root through the native constructor invoker, reject null/failed custody and
  contain constructor exceptions. Preserve the static-method workaround. The
  only other current caller, keyboard-layout observation, already checks and roots
  the returned delegate before subscribing; failure still declines observation.
- **Comparator characterization:** expose the existing short comparator chain to
  a game-free fixture, comparing it against the four frozen-source wrapper bodies.
  The fixture covers 1,152 roster/assignment, delegate/native direction, locked,
  tie and optional-comparer combinations. It does not invoke real native comparers
  or construct a managed menu.
- **Pin bind episodes:** SetWidgetData revokes in-flight click/drag state and advances
  the generation even if the same ship/context reappears. Reuse valid weak context
  custody rather than allocating another handle for an unchanged context. This
  strengthens source behavior and closes the target's incomplete episode guard;
  a refreshed native row cannot complete an earlier gesture.
- **Pin ordering:** the pure ordering functions and pending receipt helper retain
  source semantics. The target's rooted all-row acquisition, in-place verified
  writes/rollback and matching-context delayed redraw are safety improvements to
  preserve. No replacement sort/state pipeline was justified by this scan.
- **Presets:** source contract and the precise native gap are recorded; no native
  hooks, settings availability, state writes or experimental handoff are activated.
  The remaining work is a dedicated native adapter with source + receiver-map
  postconditions, checked replacement synchronization and reentry/release/failure
  qualification. Do not count this as a completed fourth port.
