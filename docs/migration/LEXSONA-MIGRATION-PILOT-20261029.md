## What this says about the product

Fresh CLI derivations also exercised the actual endpoint and buff file contexts;
endpoint-task-receipt.json and buff-task-receipt.json retain their exact inputs.
Both select the same immutable persona and yield its same five duties, alongside
the baseline constraints. There are no contextual learned rules in this trial.
Different source categories did not automatically retrieve different feature
knowledge. Context specificity and evidence retrieval need their own evaluation.

The final assertion-enabled Windows suite passed424/424 steps after extending
buff-list custody through native consumption. See
[candidate qualification](QUALIFICATION-20261029-SONA-MIGRATION.md) for built
artifact identity and the limits of native qualification.

1. Explicit task selection is feasible without changing the core or widening
   scope. The previous fixed-persona adapter was an integration limitation.
2. A useful understanding package includes current intent, authoritative source,
   prior decisions and discriminating evidence. A persona helps decide what to
   attend to; it does not supply missing source knowledge. Lex continuity,
   repository contracts and real source remain necessary inputs.
3. Five relevant duties are readable. The full receipt is about24KB; exact
   context-cost.json records byte sizes. Saving full evidence and exposing a
   concise readout reduced this task's visible output, but the general MCP API
   still lacks compact, same-receipt readback. No measured latency improvement.
4. Explicitly choosing this persona replaces the adapter default for that
   request; it does not implement persona inheritance/composition. Both kinds
   of guidance were already in this conversation. Product design should clarify
   task lenses versus layered defaults without inventing composition semantics.
5. No evidence yet proves better engineering outcomes than the old skill or
   identical plain text. The observed value is selection/provenance and a small
   decision lens applied to real work; cost and outcome comparisons remain open.
6. The persona host is scoped to canonical Downstream. Its file-context strings
   do not establish which worktree/revision was inspected. The migration's source
   contracts and AX candidate identities supply that separate link. An eventual
   understanding bundle should expose the relationship instead of inviting a
   consumer to infer source provenance from a behavioral receipt.

Do not retire the skill yet. A later independent migration session should recover
the persona, evidence and return point without reading the skill, then record
what it needed and what decisions changed. Keep corrections reviewed/frozen
between trials rather than silently learning new rules during a run.
